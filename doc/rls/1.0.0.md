## Release 1.0.0 – Changelog Summary

Initial stable release of **avalynxofficeeas**, the ActiveSync (EAS)
extension for AvalynxOffice — mail, contact and calendar synchronization
from devices over the shared database, with licensing enforcement, CI
quality gates and Docker delivery.

* **ActiveSync Endpoint (Z-Push 2.7.6)**
  The `/Microsoft-Server-ActiveSync` endpoint is served by the bundled
  Z-Push 2.7.6 request processor with a clean response bridge.
  iOS, Android and Outlook devices synchronize against AvalynxOffice out of the box.
* **Shared-Database Backend**
  Own Doctrine models map the AvalynxOffice PostgreSQL schema — the schema is
  the interface, no core code is used (AGPL aggregation boundary).
  Deterministic folder ids keep mail, contact and calendar folders stable across devices.
* **Licensing Enforcement**
  Device-initiated writes (read flags, favorites, moves, deletes, folder and
  contact changes) are blocked while the core reports `READ_ONLY`.
  Outgoing device mail is stored with a license hold instead of being queued.
* **Outgoing Mail Hand-Off**
  SendMail, SmartForward and SmartReply convert RFC822 messages into outgoing
  emails and hand them to the core mail queue.
  SMTP delivery and licensing decisions remain in AvalynxOffice.
* **Attachments, Provisioning and Ping**
  Segment-based attachment storage shared with the core, ItemOperations
  attachment fetch, Z-Push provisioning and long-poll ping backed by real
  folder statistics.
  Keeps devices responsive without a dedicated daemon.
* **Quality Gates**
  PHPUnit integration suite against a real PostgreSQL schema, PHPStan level
  max, ECS and Rector wired as `composer ci` and enforced by a GitHub Actions
  workflow on every push and pull request.
* **Docker Delivery**
  PHP 8.5 production image (`latest` on the default branch, semver tags for
  releases) plus a dev image with the dev dependencies
  (`jbsnewmedia/avalynxofficeeas-dev`) as the runtime for local test runs,
  published by the docker-image workflow.
  Ready for the `avalynxofficedocker` compose stack.
